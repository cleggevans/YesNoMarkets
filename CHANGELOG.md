# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release of YesNoMarket
- Core prediction market functionality
- Market creation with custom questions and end times
- YES/NO share trading with AMM pricing
- Market resolution and winnings claims
- Liquidity provision and management
- Configurable platform and creator fees
- Support for native BNB and ERC20 tokens
- Comprehensive test suite
- Deployment scripts for BSC Testnet and Mainnet
- Documentation and examples

### Security
- ReentrancyGuard protection
- Access control via Ownable
- SafeERC20 for token transfers
- Input validation on all functions

### Documentation
- README with setup instructions
- Architecture documentation
- Deployment guide
- Security policy
- Contributing guidelines
- Usage examples
